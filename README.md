# QuoteImage mobile

Flutter Android/iOS client for local image preprocessing and BLE transfer.

```sh
flutter run -d <device-id> apps/mobile/lib/main.dart
flutter test apps/mobile
flutter analyze apps/mobile
```

The image pipeline runs in a background isolate. Atkinson mode uses serpentine
scanning plus deterministic threshold jitter to reduce directional banding in
smooth gradients. The output preview and transferred `MONO_HMSB` frame are
generated by the same pixel loop, so the phone preview reflects the frame sent
to the panel.

New devices display a four-digit code. Use the device switcher to add the
device and enter that code. The app stores the device's advertised MAC as its
identity, saves the 128-bit credential in Android Keystore or iOS Keychain
storage, and remembers the last selected device. Renaming updates the global
name on the display; unpairing clears the only authorized credential and makes
the panel show a new code.
